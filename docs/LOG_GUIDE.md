# How to log: my routine exercises

The sheet behind **How to log?** on each exercise page. The rule follows the load type (your override from the logger's Weight steps…, else the classification in `load_types.dart`).

| Routine | Exercise | Load type | Rule | Bar / sled / carriage |
|---|---|---|---|---|
| Upper | Chest Press | Plate-loaded, both sides | Log total plates on both sides | Plates only: the sled or carriage’s own weight is not counted. |
| Upper | Straight Arm Pulldown | Stack / cable | Log the stack weight | Just the stack: handles, ropes and bars are not counted. |
| Upper | Machine Chest Fly | Stack / cable | Log the stack weight | Just the stack: handles, ropes and bars are not counted. |
| Upper | Chest Supported T-Bar Row | Plate-loaded, one side | Log total plates on the sleeve | Plates only: the lever or arm’s own weight is not counted. |
| Upper | Dumbbell Incline Y Raise | Dumbbell | Log the weight of ONE dumbbell | Just the dumbbell: nothing else is added. |
| Lower | Lying Leg Curl | Stack / cable | Log the stack weight | Just the stack: handles, ropes and bars are not counted. |
| Lower | Pendulum Squat | Plate-loaded, one side | Log total plates on the sleeve | Plates only: the lever or arm’s own weight is not counted. |
| Lower | Leg Extension | Stack / cable | Log the stack weight | Just the stack: handles, ropes and bars are not counted. |
| Lower | Walking Lunge | Dumbbell | Log the weight of ONE dumbbell | Just the dumbbell: nothing else is added. |
| Lower | Sled Press Calf Raise | Plate-loaded, both sides | Log total plates on both sides | Plates only: the sled or carriage’s own weight is not counted. |
| Lower | Back Extension | Bodyweight | Log only the weight you add | Your bodyweight is added automatically for ranks; it is not part of the number. |
| Push | High-to-Low Cable Fly | Stack / cable | Log the stack weight | Just the stack: handles, ropes and bars are not counted. |
